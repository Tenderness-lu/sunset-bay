Sunset Bay — a 3D open-world crime game set in a sun-soaked coastal city. Drive and steal cars, dodge the law across a 0–5 star wanted system, run jobs for Marla Vane, and explore on foot or behind the wheel. Built with Three.js; runs entirely from static files in your browser.

## Run it

```sh
python3 -m http.server --directory game 8000
# then open http://localhost:8000 in a desktop browser
```
